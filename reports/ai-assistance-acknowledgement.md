## Statement

This project used AI assistance as a coding and documentation tool during development. In line with Section 15 of the Joint DSA Project Brief, all AI assistance is fully acknowledged here. All team members can explain and modify their own implementations independently.

---

## What AI Was Used For

| Category | Description |
|---|---|
| Code structure | Suggesting standard Maven directory layouts and Java package conventions |
| Pseudocode | Drafting pseudocode blocks for Priority Dispatch, Dijkstra, Kruskal, B-Tree, and Stack Undo Log |
| Proof sketches | Structuring the formal proof sketches for Selection Sort, Dijkstra, and the Greedy Exchange Argument |

| Documentation | Writing and formatting `README.md` and inline JavaDoc comments |

---

## What AI Was NOT Used For

- All original core data structure logic (B-Tree splitting, Red-Black Tree rotations, DisjointSet union-rank, HashTable chaining with resizing) was written by team members and later reviewed or cleaned up with AI assistance.
- All performance experiments, raw timing data, and empirical analysis were produced by running actual Java code on the team machine — not generated by AI.
- All Ghana localisation details (ECG Accra/Legon network structure, crew types, fault categories, and community names) were researched and written by the team, not AI.
- All oral defense preparation notes and individual explanations were written by team members.

---

## How We Can Modify Our Implementation

Each team member is assigned to specific data structures and algorithms (see Implementation Plan). In the oral defense, any examiner question such as:

- "Change the priority rule so lower urgency numbers dispatch first."
  → Modify `PriorityQueue.java` `compareTo` and `Fault.compareTo` to return `this.urgency - other.urgency` instead of the reverse.

- "Add a new location between L020 and L035."
  → Insert into `locations.csv`, add a road record in `roads.csv`, re-run `GraphService.loadGraph()` to rebuild the adjacency list.

- "Change the hash table size to use a different prime."
  → Modify `TeamParameters.HASH_CAPACITY` and construct `HashTable` with `new HashTable<>(TeamParameters.HASH_CAPACITY)`.

All of these changes can be made live, demonstrated, and explained by the assigned team member.
